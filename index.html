На телефоне
MyPlan сделан адаптивным: интерфейс перестраивается под экран смартфона. Для загрузки выписки достаточно открыть сайт в браузере и выбрать файл из телефона.
MyPlan хранит данные локально в браузере. Для банковских выписок не используй сторонние сайты без необходимости.
